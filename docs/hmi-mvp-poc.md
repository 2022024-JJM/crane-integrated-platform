## 1. 개요

기존 GSI(지에스아이㈜) 크레인 충돌 방지 시스템의 터치패널 HMI(BENECOM BNC-10T-G, 1024×768)를
크레인 통합 플랫폼 내 웹 기반 HMI 페이지로 동일하게 재현한 **Hanwha MVP PoC** 결과를 정리한다.

- **목표**: 기존 GSI HMI 매뉴얼(2021, DSME Anticoll)의 화면 구성·기능을 웹에서 100% 동일하게 재현
- **브랜딩**: 화면 타이틀 등 브랜딩은 **Hanwha**로 적용 (GSI는 비교 원본으로만 참조)
- **범위**: 화면 UI 전체 + 충돌 영역 판정/알람 동작 (데이터는 시뮬레이션 기반)
- **제외**: 실제 PLC 연동 (향후 WebSocket 연동 예정)

## 3. 기능 재현 내역

### 3.1 충돌 영역 판정 (매뉴얼 2.3)

Master ↔ Slave 거리 기준 4영역(안전/정지/미속/근접) 판정. 3축(종류별 상이) 모두 판정하며,
미속거리는 정지~근접 사이 중간값으로 자동 산출(매뉴얼: 속도 가변). 기준값은 매뉴얼 권장값을
기본으로 하되 **장비 재설정 화면에서 수정·저장 가능**(localStorage 영속화, `model/limits.ts`).

| 종류 | 축 | 안전거리 | 정지거리 | 근접거리 |
|---|---|---|---|---|
| TC/TTC | 횡행(m) | 3 | 6 | 8 |
| TC/TTC | 선회(m) | 3 | 8 | 25 |
| TC/TTC | 주행(m) | 3 | 8 | 12 |
| GC | UT/LT(m) | 3 | 5 | 8 |
| GC | 주행(m) | 3 | 6 | 12 |
| OC/CC | 인입(m) | 3 | 5 | 8 |
| OC/CC | 선회(m) | 3 | 8 | 25 |
| OC/CC | 주행(m) | 3 | 6 | 12 |

영역 판정 결과는 시뮬레이션 속도에 피드백된다(매뉴얼 2.3의 PLC 제동 동작 재현):

- **미속영역** 접근 시 해당 축 속도 0.35배 감속
- **정지영역** 접근 시 해당 축 정지 → 일정 시간 후 후퇴(역방향 재개)
- **안전영역**은 접근 불가 (진입 차단)

### 3.2 영역별 알람 동작

| 영역 | 화면 | 부저 | 재현 여부 |
|---|---|---|---|
| 근접 | 3초간 노란색 점멸 | 0.5초 | ✅ (부저 제외) |
| 미속 | 3초간 주황색 점멸 + 감속 | 0.3초 | ✅ (부저 제외) |
| 정지 | 3초간 빨간색 점멸 + 정지 | 0.2초 | ✅ (부저 제외) |
| 안전 | 접근 불가 영역 | — | ✅ (진입 차단) |

- 점멸 3초 후 영역 체류 중에는 해당 색상 유지 (매뉴얼 스크린샷과 동일)
- 부저는 운영 결정에 따라 **제외** (`model/buzzer.ts`는 보존, 호출 안 함)
- 충돌 정보 패널에 대상 크레인 번호·접근 방향 화살표·잔여 거리 표시
  (근접/미속 = 노란색, 정지 = 빨간색)
- **무알람 상태에서도 표시 범위(30m) 내 최근접 크레인·거리를 흰색으로 상시 표시** (매뉴얼 2.6 화면)

### 3.2-1 마스터 종류별 화면 분기 (매뉴얼 2.2)

하단 바의 `마스터: {종류} (데모)` 버튼으로 TTC → GC → OC 순환 전환.

| 종류 | 동작상태 행 | 맵 도형 | 시뮬레이션 시나리오 |
|---|---|---|---|
| TTC (TC) | 하중 / 횡행(m) / 선회(°) / 주행(m) | 선회원 + 붐 + 트롤리(붐 위 실위치) | GC-01 방향 주행 + 연속 선회 + 트롤리 왕복 |
| GC | 하중 / UT(m) / LT(m) / 주행(m) | 거더 + 트롤리 2개 | TTC-05/OC-04 선회영역 방향 주행 + UT/LT 횡행 (레일 1조당 GC 1대) |
| OC (CC) | 하중 / 인입(°) / 선회(°) / 주행(m) | 선회원 + 본체 + 붐(인입각 따라 길이 변화) | 인입 왕복 + 선회 + 주행 |

충돌 정보 패널 행도 종류별 축 구성에 맞춰 변경된다.

### 3.3 상단 타이틀 바 상태 아이콘

| 아이콘 | OFF | ON | 재현 여부 |
|---|---|---|---|
| 컨트롤 | 어두움 | 녹색 | ✅ (클릭 토글 데모) |
| 충돌 방지 바이패스 | 어두움 | 빨간색 | ✅ (클릭 토글 데모) |
| PLC-HMI 통신오류 | 어두움 | 노란색 | ✅ (클릭 시 Slave 빨간 표시 연동) |

## 5. 시뮬레이션 시나리오 (데모 방법)

PoC는 PLC 미연동 상태로, 아래 시나리오가 자동 반복된다.

1. Master(TTC-01)가 선회(3°/s)하며 하단 GC-01 방향으로 주행(2m/s) 왕복
2. GC-01 접근 시 **근접(노랑) → 미속(주황, 감속) → 정지(빨강, 정지 후 후퇴)** 알람 순차 발생
3. 붐 끝단이 TTC-05/OC-04 선회영역·GC-01 레일에 접근할 때 **선회 충돌 알람** 발생
4. 트롤리가 바깥쪽으로 이동하며 장애물에 접근할 때 **횡행 충돌 알람** 발생
5. 통신오류 아이콘 클릭 → TTC-05 빨간색 표시 (매뉴얼 2.4 데모)
6. 장비 설정 5회 연속 클릭 → 장비 재설정 + 충돌 기준값 설정 화면 진입
7. 하단 `마스터: TTC (데모)` 버튼 → GC/OC 마스터 화면 전환 (각각 고유 시나리오)
