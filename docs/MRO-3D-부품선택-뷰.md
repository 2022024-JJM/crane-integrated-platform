# MRO 자산관리 — 3D 부품 선택 뷰

> 자산 상세 페이지에 인터랙티브 3D 크레인 뷰를 추가하여, 크레인 구역을 마우스로 선택하면 해당 구역에 매칭되는 BOM 부품 재원을 바로 확인할 수 있습니다. 함께 사이트(도크) 체계를 실제 현장 기준(4도크 단일)으로 정리하고, 크레인 100대 확장을 고려한 구조로 재설계했습니다.

---

## 1. 배경 및 목적

| 항목 | 내용 |
|---|---|
| 기존 | 자산 목록 카드의 "3D" 버튼 클릭 시 카드 아래에 단순 3D 뷰어만 표시 (조회 외 상호작용 없음) |
| 문제 | 3D 모델과 BOM(부품) 데이터가 분리되어 있어, 특정 부위의 부품 정보를 찾으려면 구성품 트리를 별도로 탐색해야 함 |
| 개선 | 3D 크레인에서 구역(부위)을 직접 클릭 → 우측 패널에 해당 구역의 부품 재원 즉시 표시 |
| 부가 | 사이트 체계 4도크 단일화, 자산 목록 검색·페이징 등 100대 확장 대비 |

---

## 2. 사용자 플로우

```
자산 목록 카드 [3D] 버튼
        │
        ▼
자산 상세 › "3D 뷰" 탭  (/asset-management/{craneId}?tab=3d)
        │
        ├─ 3D 모델에서 구역 hover  →  하이라이트 + 포인터 커서
        ├─ 구역 클릭              →  카메라 줌인 + 우측 패널에 구역 부품 목록
        │       └─ 부품 클릭      →  부품 재원 카드 (P/N · 제조사 · 상태 · 잔여수명)
        └─ 빈 공간 클릭 / 전체 보기 →  정면 전체 뷰 복귀
```

- 목록 카드의 **3D 버튼은 상세 페이지 3D 탭으로 이동**하도록 변경 (딥링크 `?tab=3d`, 새로고침에도 탭 유지)
- 우측 패널 상단의 **구역 칩**으로도 동일하게 선택 가능 — 칩에 hover하면 3D 모델도 함께 하이라이트되어 양방향 연동

## 3. 3D 뷰어 — 구역 선택

### 3.1 660T 골리앗 크레인 (파트 분리 모델)

골리앗 크레인은 부위별로 분리된 3D 모델 4개를 조립 렌더링하여, **실제 메시 단위로 hover/클릭 선택**이 가능합니다.

| 구역 | 매칭 BOM 클러스터 (예) |
|---|---|
| 본체 / 거더 (Body) | 배전·보호, 변압기, PLC, 네트워크, 배선, 함체, 운전·컴퓨팅·CCTV 등 전장 대부분 |
| 트롤리 (Trolley) | DCM 드라이브, 모터 스타터, 기계 구동계, 조작 기기 |
| 호이스트 로프 (Hoist Rope) | 기계 구동계, 센싱 |
| 후크 (Hook) | 센싱, 경보 |

- hover 시 해당 파트가 블루 톤으로 하이라이트
- 클릭 시 해당 파트로 카메라 줌인 + 나머지 파트는 반투명 처리
- 선택 파트에는 바운딩 박스 표시

**[이미지: 660T — 트롤리 hover 하이라이트]**

**[이미지: 660T — 트롤리 선택 상태 (줌인 + 타 파트 반투명 + 우측 패널 부품 목록)]**

### 3.2 50T 러핑 크레인 (영역 분류 방식)

50T 모델은 단일 메시 모델이라, 클릭 지점을 크레인 바운딩 박스 기준 **정규화 영역으로 분류**하는 방식을 사용합니다. 통짜 모델에서도 구역 선택이 가능합니다.

| 구역 | 영역 (높이 기준) | 매칭 클러스터 (예) |
|---|---|---|
| 붐 / 지브 | 상부 | 센싱, 경보, 기계 구동계 |
| 운전실 | 중부 전면 | 운전 장치, 컴퓨팅, CCTV, 조작 기기 |
| 기계실 | 중부 | PLC, 네트워크, 퓨즈, 파워서플라이, 함체, 계측, 드라이브 |
| 주행부 / 베이스 | 하부 | 배전, 변압기, 배선, 서지, 전류 센싱, 저항 |

- hover 시 해당 영역에 반투명 블루 박스 오버레이 표시
- 클릭 시 선택 상태로 고정 + 우측 패널 갱신

## 4. 부품 재원 패널 (우측)

| 상태 | 표시 내용 |
|---|---|
| 기본 (미선택) | 안내 문구 + 구역 칩 목록 |
| 구역 선택 | 해당 구역의 BOM 클러스터(접이식) → 부품 행 (상태 도트 · 부품명 · P/N · 수명 바) |
| 부품 선택 | 부품 재원 카드: **부품명 · P/N · 제조사 · 상태 배지 · 잔여수명 게이지**(사용시간/기대수명) |

- 잔여수명 게이지는 사용률 기준 3단계 톤 (정상 / 주의 ≥70% / 위험 ≥90%)
- 컬러는 MRO 공용 톤 팔레트(tone.ts) 기준으로 통일

## 7. 확장성 설계 (크레인 ~100대 대비)

| 영역 | 설계 |
|---|---|
| 3D 구역 설정 | `craneType` 단위 설정(`crane-zone-config.ts`) — 새 크레인은 타입만 맞으면 3D 구역 선택 자동 지원. 미매핑 타입도 상/중/하 3밴드 폴백 제공 |
| 목록 섹션 | 하드코딩 제거 → 사이트 카탈로그(`sites.ts`) + 자산 데이터의 siteId에서 파생. **도크 추가 = 데이터 변경만** |
| 목록 탐색 | 자산명/S/N/모델/제조사/위치 검색 + 상태 필터 + 섹션당 10개 페이지네이션 |
| 렌더링 성능 | 카드마다 생성되던 인라인 WebGL 캔버스 제거 (3D는 상세 탭에서만 렌더) |

**[이미지: 자산 목록 — 검색 + 상태 필터 + 페이지네이션]**

## 8. 기술 구현 요약

```
packages/domain/src/3d/model/crane-zone-config.ts   ← 구역 설정 (타입별 전략/존/클러스터 매핑)
apps/philly-shipyard/src/pages/asset-management/
  ├─ ui/asset-3d-tab.tsx          ← 3D 탭 (선택 상태, 존→클러스터→부품 매핑)
  ├─ ui/crane-3d-zone-viewer.tsx  ← 좌측 3D 뷰어 (parts/regions 전략, 카메라 프레이밍)
  ├─ ui/zone-spec-panel.tsx       ← 우측 부품 재원 패널
  ├─ lib/zone-hit.ts              ← 히트 지점 → 구역 분류 (regions 전략)
  └─ lib/compute-frontal-view.ts  ← 정면 뷰 카메라 계산
apps/philly-shipyard/src/shared/config/sites.ts     ← 사이트 카탈로그 (4도크)
```

- **두 가지 구역 선택 전략**
  - `parts`: 구역별 분리 GLB 조립 렌더 (660T — gc-04 body/trolly/hook/rope 4파트, 실제 메시 클릭)
  - `regions`: 단일 모델 + 레이캐스트 히트 지점의 정규화 좌표를 영역으로 분류 (50T 등 통짜 모델)
- 기존 3D 인프라 재사용: `GltfModel`(선택/hover/하이라이트 prop), BVH 가속 레이캐스트, `ThreeSceneViewer` 카메라 컨트롤러
- 도메인 변경은 hover 콜백에 optional 이벤트 인자 추가 1건 (기존 호출부 무영향)
- 구역→클러스터 매핑은 21개 BOM 클러스터 전부 도달 가능하도록 구성 (중복 허용, 설정으로 조정 가능)

## 9. 알려진 한계 / 향후 과제

- 50T 영역 경계값은 모델 실루엣 기준 추정치 — 필요 시 `crane-zone-config.ts`의 수치만 조정
- 660T는 gc-04 모델을 사용하므로 기존 gantry 단일 모델 대비 외형이 다름 (파트 선택을 위한 의도된 교체)
- 구역→클러스터 매핑은 도메인 검토 후 정밀화 필요 (현재는 합리적 추정 매핑)
- 부품 재원 패널은 BOM 정보만 표시 — 재고/점검·정비 이력 연동은 추후 확장 후보
