# CRANE OPS — MRO MVP 개발 보고서

> HPSI(필라델피아 조선소) 크레인 자산의 **정비·수리·운영(MRO, Maintenance·Repair·Operations)** 통합 관리 MVP
> 대상 설비: 660T Goliath Crane, 50T East Luffing Crane (2기)

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 크레인 자산의 점검·정비·재고·규제 이력을 한 플랫폼에서 관리하고, 발견→조치→추적으로 이어지는 운영 루프 구현 |
| 범위 | MRO 대시보드 · 자산 관리 · 점검 관리 · 정비 관리 · 부품/재고 · 서비스 캘린더 · OSHA 규제 · 티켓 생성 |
| 데이터 기준 | HPSI 실제 BOM(전장품 306품목)을 단일 소스로 삼아 인벤토리·자산 구성품·발주가 모두 파생 |
| 다국어 | 한국어 / 영어 / 라틴어(la) 3개 언어 전면 지원 |
| 아키텍처 | 모노레포(FSD) — `domain`(데이터·타입) / `features`(조회·커맨드 훅) / `ui`(공용 컴포넌트) / `widgets`(레이아웃) / `apps`(페이지) |

---

## 2. 데이터 기반 — BOM 단일 소스(Single Source of Truth)

- HPSI 크레인 2기의 전장품 BOM **306품목**을 `bom-catalog.ts`에 단일 정의(21개 클러스터: 전력분배·PLC·DCM 드라이브·모터스타터·센싱·네트워크 등).
- **인벤토리 재고 마스터**, **자산 구성품 트리(클러스터→개별 부품 2계층)**, **구매 발주(PO)**가 모두 이 카탈로그에서 파생 → 부품번호·제조사·적용 크레인이 전 화면에서 일관.
- 수리 WO 스토리(주행 모터·기복 DCM·UPS 배터리·PLC CPU 등)와 재고 수량·트랜잭션 원장이 정합하도록 시드.

## 3. 페이지별 기능

### 3.1 MRO 대시보드

![MRO 대시보드](images/01-mro-dashboard.png)

- 핵심 운영 지표(가동률·미결 WO·긴급 항목)와 주요 업무로 이동하는 퀵링크 제공.
- 서비스 캘린더·자산·점검·정비·재고·규제로 진입하는 허브.

---

### 3.2 자산 관리 — 목록

![자산 관리 목록](images/02-asset-management-list.png)

- **크레인 1기당 전폭 서머리 카드**로 재설계(기존 다수-크레인용 그리드 → 2기 실데이터에 맞춤).
- 카드 1장에 상태·구성품 건강도(최저 잔여수명 바)·이상 구성품 카운트(위험/경고/주의)·미결 WO·다음 점검 D-day·보증 상태를 한눈에.
- 상태 필터 pill, 사이트별(Dock/Block Shop) 섹션 그룹, 우선순위 정렬.
- 상단 KPI 카드: 가동률 / 위험 구성품 / 보증 알림 / 미결 작업지시.

### 3.3 자산 관리 — 상세

![자산 관리 상세](images/03-asset-management-detail.png)

- **요약 헤더 밴드**(크레인명·상태·제원 요약 + 구성품 상태 롤업 + 미결 WO + 다음 점검) 상시 노출.
- 탭 구성: **구성품(BOM) / 점검 이력 / 정비 이력 / 제원**.
- BOM 탭: **부품명·P/N 검색 + "이상 항목만" 필터 + 클러스터 접이식 컴팩트 행**으로 246품목도 탐색 가능.
- 각 부품 행 → **인벤토리 부품 상세로 딥링크**(재고 즉시 확인).

---

### 3.4 점검 관리 — 목록

![점검 관리 목록](images/04-inspection-list.png)

- 점검 WO 목록: 상태(예정/진행/완료/지연/취소)·유형(수시/정기/긴급/특별) 필터, 예정일 D-day, 진행률.

### 3.5 점검 관리 — 상세

![점검 관리 상세](images/05-inspection-detail.png)

- 체크리스트 판정(적합/부적합/해당없음) 인라인 편집, 진행률 바, 결과 제출.
- **부적합 항목 요약 블록** + **"수리 티켓 생성" CTA** — 크레인·부적합 구성품·원천 점검번호를 프리필해 티켓 생성으로 즉시 연결(발견→조치).
- 크레인명 → 자산 상세 링크.

---

### 3.6 정비 관리 — 목록/칸반

![정비 관리 목록](images/06-maintenance-list.png)

- 수리 WO 상태 파이프라인(접수→부품대기→진행→재검사→완료) 칸반, 우선순위·상태 색상 구분.

### 3.7 정비 관리 — 상세

![정비 관리 상세](images/07-maintenance-detail.png)

- WO 정보·사용 부품·비용·근본원인(RCA)·조치 이력.
- **크로스링크 3종**: 크레인명 → 자산 상세, 사용 부품 → 인벤토리 부품 상세, 원천 WO → 점검 상세.
- 상태 배지 색상을 리스트/칸반과 동일 체계로 통일.

---

### 3.8 부품/재고 — 목록

![부품/재고 목록](images/08-inventory-list.png)

- 재고 마스터 306품목: **현재고 / 예약 / 가용 / 단위(UOM)** 컬럼, 재고 수준 바.
- 상태·중요도 멀티셀렉트 필터(건수 표시), 크레인(660T/50T/공용) 필터, 부품명·P/N·제조사 검색.
- 안전재고 미달 알림 배너, 진행 중 발주(PO) 요약.

### 3.9 부품/재고 — 상세 패널

![부품/재고 상세 패널](images/09-inventory-detail-panel.png)

- 우측 슬라이드 패널(부드러운 슬라이드 인/아웃 + 본문 밀기로 테이블 미가림).
- **재고 요약 5칩**: 현재고 / 예약 / 가용 / 발주중 / 재주문점.
- 탭: 부품 정보 / 입출고 이력(원장) / WO 사용 이력.
- **발주중(Open PO)** 목록 + **System 자동 재발주** 표기.
- 출고·입고 액션(가용 재고 기준 검증, 수리 WO 연동).
- 전체화면 확장 뷰(탭 → 3열 병렬), 확장 시 좌측 메뉴 미가림.

### 3.10 서비스 캘린더 (신규 개발)

![서비스 캘린더 - 월](images/10-service-calendar-month.png)

![서비스 캘린더 - 주](images/11-service-calendar-week.png)

- **구글 캘린더형 월/주/일 3개 뷰**(세그먼트 토글 전환, 이전/오늘/다음 네비).
- 이벤트 소스: **점검 WO(예정일, 종일) + 정비 WO(예정 기간)**.
- **색상 범례**: 점검=상태축 / 정비=우선순위축(같은 색이 축별로 다른 의미임을 명시).
- **멀티데이 이벤트** 지원(월=걸치는 모든 날, 주/일=상단 종일 스트립).
- 이벤트 클릭 → 요약 팝오버(제목·크레인·상태·시간) → 기존 상세 페이지로 이동.
- 사이드바 메뉴·라우트·i18n 네임스페이스 신규 배선.

## 4. 이번 개발/개선 하이라이트

### 4.1 MRO 왕복 내비게이션 완성 (상호 추적 그래프)
점검·정비 상세가 자산·부품·원천 WO로 나가지 못하던 **막다른 길**을 해소:

| 출발 → 도착 | 자산 | 점검 WO | 정비 WO | 인벤토리 부품 |
|---|:---:|:---:|:---:|:---:|
| 자산 상세 | — | ✅ | ✅ | ✅ |
| 점검 상세 | ✅ | — | ✅(티켓 생성) | — |
| 정비 상세 | ✅ | ✅(원천 WO) | — | ✅ |

→ **점검에서 부적합 발견 → 수리 티켓 생성 → 정비 상세에서 크레인·부품·원천 점검으로 왕복**하는 운영 루프 완성.

### 4.2 인벤토리 심화
- 예약/가용 재고를 1급 지표로 승격, **가용 재고 기준 출고 검증**으로 일관성 확보.
- 발주중 수량·예상 입고일, System 자동 재발주 서사, UOM(벌크 케이블 M 단위) 도입.
- 상세 패널 ⇄ 전체화면, 부드러운 슬라이드 + 본문 밀기로 가독성 확보.

### 4.3 서비스 캘린더 신규 구축
- 라이브러리 없이 네이티브 Date 기반 월/주/일 뷰, 색상 범례, 멀티데이, 팝오버 딥링크.

### 4.4 품질·접근성
- 출고/입고 모달 **ESC 레이어링 버그** 수정(입력 데이터 손실 방지).
- 하드코딩 aria-label i18n화 등 다국어 누출 정리.
