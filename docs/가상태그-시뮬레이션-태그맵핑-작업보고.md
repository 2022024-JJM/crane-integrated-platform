# 가상 태그 시뮬레이션 + 태그 맵핑 구조 개선 작업보고 (2026-09-02)

## 배경

3D 편집기의 "태그 맵핑"은 서버(PLC) 태그 값을 모델 트랜스폼에 적용해 현장을 재현하는 기능이다. 서버가 없어 태그명을 손으로 치고, 모델 루트의 위치/회전 x·y·z 6칸에 고정돼 있었다. 별도로 리깅 탭의 "태그 바인딩"(`rigBindings`)이 있었지만 런타임이 배선되지 않아 저장만 됐다.

## 변경 요약

| 영역 | 이전 | 이후 |
|---|---|---|
| 맵핑 스키마 | `valueMapList`(루트 PX…RZ 절대 대입) + `rigBindings`(관절) 두 벌 | `tagMappings[]` 하나. 대상 = 노드(루트 포함)·채널·축 또는 리그 관절. 적용 = `offset + value×scale` 를 rest 기준 Δ |
| 태그 선택 | 자유 텍스트 입력 | 콤보박스(`useTagCatalog`) — 지금은 가상 태그, 나중에 서버 태그 합산 |
| 값 소스 | 하드코딩 삼각파 생성기(`use-value-generator-store`) | 가상 태그 정의(수동 + 파형 4종, 배포 파일 `public/simulation/virtual-tags.json` 기준·씬과 같은 저장 규칙) + 모듈 전역 러너 |
| 값 버스 | `useValueMapperStore.applyValue` (Object3D 직접 mutate) | `publishTagValue` → 바인딩 소스 → `rigValueStore` → `useRigDriver` |
| 모니터링 뷰 | 리그 드라이버 없음 | `RigDriver` + `useTagBindingSource` 상시 |
| 에디터 | 슬라이더만 | 팔레트 "태그" 탭 재생 토글로 가상 태그 값이 흐름. 재생 중 태그 꽂힌 관절 슬라이더 잠금 |
| 페이지 | 없음 | `virtual-tags` 서브라우트(3갈래 공유) — CRUD·패턴·재생·저장(미저장 이탈 경고) |

## 마이그레이션

- 로드 시 `sanitize-tag-mappings.ts` 가 `valueMapList`/`rigBindings` 를 `tagMappings` 로 변환한다. 저장하면 새 필드로 나가고 레거시 필드는 사라진다.
- 절대 좌표 → Δ 변환: `offset' = offset − placement[axis]`. `dock-in.json` 의 `PZ offset 71` 은 다음 저장 때 `offset 71 − position.z` 로 바뀌며 결과 좌표는 같다(테스트로 고정).
- `rigBindings` 실데이터는 0건이었다.

## 테스트

- domain: 파형 결정론·경계(수동 + 정현·구형·삼각·톱니), 가상 태그 sanitize, 맵핑 sanitize·레거시 변환·멱등.
- features: 값 버스, 맵핑 인덱스, 채널 누적 적용, 드라이버 node 맵핑(루트 rest=배치, 리그 우선, 드래그 중 건너뜀), 바인딩 소스 수명, 가상 태그 스토어(fake timers).
- widgets: 충돌 판정·기본값, 키 검증, 스냅샷 비교. domain: 저장 어댑터(dev 파일/운영 봉투·stale 정리·폴백).

## 남은 일 / 주의

- 배치 회전이 0 이 아닌 모델의 회전 맵핑 레거시 변환은 단일 축일 때만 정확하다(실데이터 없음).
- 실서버 연동 시 할 일: `useTagCatalog` 에 `getMonitoringTags()` 합치기, 모드 스위치에서 WebSocket 러너를 켜기. 씬 JSON·맵핑 UI·드라이버는 무변경.
