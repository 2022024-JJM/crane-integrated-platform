# MRO 자산관리 — 3D 뷰 전기실 · 운전실 구역 추가

> 660T 골리앗 크레인 3D 뷰에서 **전기실과 운전실을 독립 구역으로 분리**했습니다. 실물 크레인의 전기실에는 PLC 판넬이 설치되어 있는데, 기존에는 본체(Body) 전체 단위로만 선택이 가능해 PLC 부품을 찾으려면 본체의 전장 클러스터 전체를 탐색해야 했습니다. 이제 3D 모델에서 전기실을 직접 클릭하면 우측 패널에 **PLC 부품 제원이 바로 표시**됩니다.

---

## 1. 배경 및 목적

| 항목 | 내용 |
|---|---|
| 현장 상황 | 660T 골리앗 크레인의 거더 끝단 전기실에 PLC 판넬(SIEMENS S7-1500 계열) 설치, 그 하부에 운전실(케빈) 위치 |
| 기존 | 3D 뷰에서 본체/트롤리/호이스트 로프/후크 4개 파트 단위로만 선택 가능 — 전기실·운전실은 본체에 통합 |
| 문제 | PLC 부품 확인 시 본체 선택 → 전장 클러스터 15종 중에서 PLC를 찾아 들어가야 함 |
| 개선 | 전기실·운전실을 **본체 안의 독립 선택 구역**으로 분리 — 전기실 클릭 시 PLC 부품 제원 즉시 표시 |

## 2. 사용자 플로우

```
자산 상세 › "3D 뷰" 탭 (660T 골리앗)
        │
        ├─ 거더 우측 끝단(전기실) hover  →  반투명 하이라이트 박스 + 포인터 커서
        ├─ 전기실 클릭                  →  카메라 줌인 + 우측 패널에 PLC · 판넬 함체 부품 목록
        │       └─ 부품 클릭            →  부품 재원 카드 (P/N · 제조사 · 상태 · 잔여수명)
        ├─ 전기실 하부(운전실) 클릭      →  운전 장치 · 컴퓨팅 · CCTV 부품 목록
        └─ 빈 공간 클릭 / 전체 보기      →  정면 전체 뷰 복귀
```

- 우측 패널의 **구역 칩에 "전기실" · "운전실" 추가** — 칩 hover 시 3D 모델의 해당 영역이 함께 하이라이트되는 양방향 연동은 기존과 동일
- 전기실 영역을 벗어난 본체 클릭은 기존처럼 "본체 / 거더" 선택으로 동작

## 3. 구역 · 부품 매핑 변경

### 3.1 신설 구역

| 구역 | 위치 (3D) | 매칭 BOM 클러스터 |
|---|---|---|
| **전기실** (Electrical Room) | 거더 상단 우측 끝단 | **PLC**, 판넬 함체(Enclosure) |
| **운전실** (Operator Cabin) | 전기실 하부 | 운전 장치, 컴퓨팅, CCTV |

### 3.2 본체 클러스터 조정

전기실·운전실로 이동한 클러스터는 본체에서 제외하여 중복 없이 정리했습니다.

| 구역 | 변경 전 | 변경 후 |
|---|---|---|
| 본체 / 거더 | 전장 15종 (PLC · 함체 · 운전 · 컴퓨팅 · CCTV 포함) | 배전·보호, 변압기, 네트워크, 퓨즈, 파워서플라이, 배선, 서지, 전류 센싱, 저항, 계측 (10종) |
| 전기실 | — (신설) | PLC, 함체 |
| 운전실 | — (신설) | 운전 장치, 컴퓨팅, CCTV |

### 3.3 전기실에서 확인 가능한 PLC 부품 (660T 기준 16개)

SIEMENS S7-1500 계열 — CPU 모듈(1516-3 PN/DP, 1515-2 PN), 전원(24VDC 3A), 아날로그/디지털 I/O 모듈, PROFIBUS 인터페이스, 통신 모듈(CP1542-5), TM 카운트 모듈, 플래시 메모리 카드, 레일, 커넥터 등. 판넬 함체(RITTAL AE 1038500)와 팬/히터/서모스탯은 함체 클러스터로 함께 표시됩니다.

## 4. 구현 방식 — 파트 내 서브 존(Sub-zone)

전기실·운전실은 별도 3D 파일이 아니라 **본체 GLB에 통짜로 포함**되어 있어, 기존 두 전략(파트 단위 선택 / 단일 모델 영역 분류)만으로는 분리 선택이 불가능했습니다. 두 전략을 결합한 **서브 존** 방식을 새로 도입했습니다.

| 항목 | 내용 |
|---|---|
| 정의 | 호스트 파트(본체)의 바운딩박스 기준 정규화 [0..1] 좌표 영역으로 구역 정의 (`subRegionsOf: 'body'`) |
| 히트 판정 | 본체 클릭/hover 시 레이캐스트 히트 지점을 서브 존 영역과 먼저 대조 → 매칭 시 서브 존, 미매칭 시 본체로 처리 |
| 하이라이트 | 서브 존 hover/선택 시 해당 영역에 반투명 블루 박스 오버레이 (50T 영역 방식과 동일한 시각 언어) |
| 카메라 | 서브 존 선택 시 호스트 박스 × 영역 좌표로 계산한 박스로 줌인 |
| 좌표 도출 | 본체 GLB 정점 실루엣 분석으로 거더 밴드(높이 상위 22%)·끝단 위치를 특정, 실물 사진과 교차 검증 |

기존 인프라(히트 분류 함수, 영역 오버레이, 정면 뷰 카메라 계산)를 그대로 재사용했으며, 설정 파일에 영역 좌표만 추가하면 다른 크레인 타입·다른 부위(예: 기계실, 판넬룸)에도 동일하게 적용할 수 있습니다.

## 5. 기술 구현 요약

```
packages/domain/src/3d/model/crane-zone-config.ts   ← CraneZone.subRegionsOf 필드 + 전기실/운전실 존 정의
apps/philly-shipyard/src/pages/asset-management/
  ├─ ui/crane-3d-zone-viewer.tsx  ← 서브 존 히트 판정(hover 이동 추적) · 오버레이 · 줌인
```

- 다국어: 전기실(ko) / Electrical Room(en) / Camera Electrica(la) — 운전실 라벨은 기존 키 재사용
- 검증: 단위 테스트 15건 통과 (영역→월드 박스 변환 테스트 2건 신규), 타입체크 통과

## 6. 알려진 한계 / 향후 과제

- 전기실·운전실 영역 좌표는 모델 정점 분석 기반 추정치 — 실제 화면 확인 후 필요 시 `crane-zone-config.ts`의 `regions` 수치만 조정
- 본체 모델에 전기실·운전실 외형이 뚜렷이 구분되지 않아 hover 하이라이트 박스가 위치 안내를 겸함 — 모델 리터칭(별도 메시 분리) 시 실제 메시 단위 선택으로 전환 가능
- 전기실 클러스터 구성(PLC + 함체)은 도메인 검토 후 조정 가능 — 변압기·배전반 등 추가는 `clusterKeys` 배열 수정만으로 반영
