# 화면 목록 — 전 시스템 화면 ID 인벤토리

**버전:** v1.3 (OT 대시보드 화면 설계서와 같은 번호를 쓴다)

화면형 시스템 3종의 화면 ID를 한 표에 모은 색인이다. **채번 권한은 각 기능 정의서 §4**에 있고, 이 표는 그것을 비추는 거울이다. 설계서가 생기면 "설계서" 열에 링크를 걸고, 기능 정의서에 반영되면 상태를 바꾼다.

- 상태: `구현` 현 구현에 있음 · `정의서` 기능 정의서 §6 정의됨 · `설계중` 설계서 Draft/Review · `확정` 설계서 Approved · `반영` 기능 정의서 반영 완료
- 기준: 기능정의서_OT대시보드 v0.1 · 기능정의서_통합실적대시보드 v0.6 · 기능정의서_Key-in실적 v0.2 (2026-10-16)
- **현재 설계 범위: OT 대시보드(§1)만.** §2·§3은 색인 목적으로만 유지하며 설계는 향후 진행한다.
