# OT 대시보드 화면 트리

내업 공정실적 자동수집 시스템 · IA 사이트맵 v0.2 (2026-10-15) · 두 개의 진입 경로가 블록 상세에서 만나는 구조 · 내부 검토용 초안

위치 축 — 현장 관리자 객체 축 — 계획 스케줄러 합류점 — 공통 공통 보조 화면 실선 = 드릴다운 · 점선 = 검색/바로가기 · 굵은 테두리 = 역할별 주 작업 화면

## 한 줄 요약

- **현장 관리자**는 장소를 따라 내려간다: 야드 맵 → 권역 → 공장 → BAY/셀 현황판. 실제로 일하는 화면은 BAY/셀 현황판이다.
- **스케줄러**는 블록으로 바로 간다: 블록 현황(호선 선택 필터, 행 = 블록 × 열 = 권역) → 블록 상세. 호선 레벨 화면은 두지 않고, 호선은 상단 선택기와 요약 스트립으로만 쓴다.
- 두 경로는 **블록 상세**에서 만난다. BAY 카드를 눌러도, 블록 현황의 행을 눌러도 같은 화면이 열리고, 들어온 경로에 맞는 권역 패널이 펼쳐진다.
- 예외 처리 큐 · 실적 이력 · 시스템 상태는 어느 경로와도 무관한 사이드 메뉴 화면이다.
- 실적 판별 센서는 조립(LiDAR·비전)과 의장(LiDAR)에만 있다. 가공은 센서가 없어 공장 현황(레거시 집계)까지만 있고, 도장은 진척은 레거시 집계로 보고 PLC(제습기·가스히터)는 셀 현황판의 설비 정보 패널로만 쓴다. 조립 BAY의 카드 1장은 블록이 아니라 **블록×송선**이며, 같은 블록이 여러 BAY에 동시에 보이는 것이 정상이다.

## 설계 전제

확정된 것만 · 확정일 2026-10-15

주 사용자

현장 관리자 · 계획 스케줄러

현장 = 장소를 따라, 스케줄러 = 블록으로 바로

위치 계층

야드*›*권역*›*공장 (복수)*›*BAY / 셀

블록 위치는 조립·조립의장 구간에서 다중값

공정 흐름

가공*→*조립 + 조립의장 S/C/A*→*선행의장 B*→*선행도장

직렬 4단계 아님. 조립의장은 조립 정반 위에서 병행

센서

가공 없음조립 LiDAR·비전의장 LiDAR도장 없음 (PLC 설비정보만)

가공·도장은 실적 판별 센서 없음 → 레거시 집계 전용. 도장 PLC(제습기·가스히터)는 부가 설비 정보, 판별 미사용

갱신 주기

실시간 = 센서 유래 상태만

레거시 값은 일 1회 + 수정일시 재조회(도장 최대 10일 소급). 화면에 레거시 기준 시각 표기

용어

권역*›*공정 단계*›*공정 상태

State Machine은 구현 설명에만. 상태 집합은 권역별

## 객체 모델 — 블록 + 권역별 작업 객체

블록은 공통 키, 실제로 세고 보는 객체는 권역마다 다르다

호선 — 선택 필터 · 요약 스트립 (화면 없음)

**블록**호선 + 블록번호현재 권역 · 권역별 진척률 · 사내/사외 · 위치 목록(다중) · Legacy 전송 상태

공통 보조: 위치(권역·공장·BAY) · 센서 이벤트

## 사이트맵 트리

Depth 1 = 사이드 메뉴(GNB) · Depth 2\~4 = 드릴다운 · 점선 박스 = 다른 가지에서 이미 정의된 화면(참조)

**D1**메뉴에서 한 번에 가는 화면 **D2**한 단계 아래 **D3\~4**두세 단계 아래 굵은 테두리 = 역할별 주 작업 화면 · 진한 박스 = 합류점 색: 위치 축 · 객체 축 · 합류점

## 화면 카드

8개 화면 · 카드 단위와 데이터 소스는 사이트맵 v0.2 §4 기준

### 위치 축 (장소를 따라 내려가는 길)

현장 관리자공통 진입

**야드 맵 (Entry)**/

역할

야드 전체 격자. BAY 칸에 체류 / 보류 / 지연 숫자만. 가공 공장은 레거시 집계 뱃지

검색

블록 → 해당 BAY 전체 하이라이트(조립은 다중) + "상세". 호선 → BAY 하이라이트 + "호선 상세" + 사외 블록 수

데이터

Hot Data DB 현재위치 집계 (NATS 구독)

**권역 현황**/zones/{권역}

역할

권역 안 공장 카드 나열. 당일 계획 대비 착수/완료/보류. 중간 계단

**공장 현황**/zones/{권역}/{공장}

역할

공장 안 BAY/셀 카드 나열. **가공은 여기가 끝**: 라인·장비별 레거시 집계, 하위 BAY 없음

**BAY / 셀 현황판** 주 작업 화면/zones/{권역}/{공장}/{bay}

카드

조립 = 블록×송선 · 의장 B = 블록×GDO · 도장 = 블록. 같은 블록이 여러 BAY에 동시 표시 가능

구성

권역별 공정 상태 칸반. 조립 카드에 조립의장 S/C/A 설치율 부착. 보류 카드 상단 고정. 호선 필터

기본셋

조립 "이번 주 이 BAY 송선 묶음"(월간계획 창) · 의장 B 활성 GDO · 도장 셀 = 레거시 반입·요소 완료 기준 블록 + PLC 설비 정보 패널(제습기·가스히터, 부가)

### 객체 축 (호선을 따라 내려가는 길)

계획 스케줄러

**블록 현황** 주 작업 화면/blocks?vessel={호선}

상단

호선 선택기(기본 = 진행 중 호선) + 선택 호선의 권역별 진행률·지연·보류·사외 블록 수 요약 스트립. 호선 전용 화면은 없음

구성

행 = 블록, 열 = 가공 · 조립(조립의장 포함) · 선행의장 B · 선행도장

셀

권역별 진척 지표 / 계획·실적일 / 상태 / 위치 요약(조립 "BAY n곳")

필터

호선(복수 선택 가능) · 지연일수 · 현재 권역 · 보류 · 사내/사외 · Legacy 전송 상태

데이터

호선·블록 마스터 미확정: 출처 + 권역별 계획 + Hot Data DB

### 합류점

현장 관리자스케줄러

**블록 상세**/blocks/{호선}/{블록}

상단

호선 · 블록 · 현재 권역 · 사내/사외 · 권역별 진척률 · Legacy 전송 상태

중단

권역 흐름 타임라인: 가공 → 조립 → 의장 B → 도장, 계획 vs 실적, 위치 이력

패널

가공(부재 단계 분포, 레거시) · 조립(송선 목록 + 조립의장 설치율 + 센서 이벤트) · 의장 B(GDO 설치율·미설치 품목 + 센서 이벤트) · 도장(요소 공정율·공식 실적률, 레거시 · 반입/반출 시각은 BTS 미확정)

진입

BAY에서 오면 그 권역 패널 펼침, 블록 현황에서 오면 타임라인 우선

액션

수동 보정 미확정: 권한·Legacy 반영

### 공통 보조 화면 (사이드 메뉴)

독립 진입

**예외 처리 큐**/exceptions

가공(입고 지연·겹장) · 조립(판별 보류·파생 송선·사외 혼재) · 의장(반출 전 미설치·W/O 없는 GDO) · 도장(중도종결·720M 미보유·0% 블록)

역할
