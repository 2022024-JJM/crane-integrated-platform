## 1. 개요

「가공권역 실적 판별 기능 정의서」의 각 기능(FAB-F01~F14)을 담당 **모듈·헥사고날 레이어** 단위까지 연결한다. 포트/어댑터 **클래스 단위** 상세 매핑은 상세 설계서에서 다룬다.

> **모듈 경계 원칙(AGENTS.md):** 가공권역 로직은 `ot-pipeline-fabrication`에 두고 **`ot-core`에만 의존**한다. 다른 `ot-pipeline-*` 모듈은 직접 참조하지 않는다. 4개 zone이 공유하는 판별 엔진(상태머신)은 `ot-core`에 둔다.

> **가공권역 특이사항:** 가공 zone은 필드 센서가 없고 MQTT Broker를 경유하지 않는다. 따라서 조립권역 매핑에 있는 **MQTT Agent 행이 존재하지 않으며**, 실적 취득은 전부 `adapter/out/legacy`(RFC/DB Agent 경유 또는 직접 JDBC) 경로다.

### 레포/소유 구분

| 컴포넌트 | 소유 레포 | 비고 |
|---|---|---|
| ot-pipeline-fabrication, ot-core | **이 레포**(ocean-inshop-process) | 판별 파이프라인·공통 엔진 |
| **RFC Agent, DB Agent** (레거시 취득: SAP RFC / Oracle·DB) | **이 레포**(ocean-inshop-process) | ISL Agent로 만들지 않고 우리 repo에서 소스 관리 |
| ProSSYS · ProMES · SAP | **연동 대상**(한화오션 레거시) | 실적 원천. 조회 전용 |
| 현장 AI Inference·전처리·모델 학습 | **범위 밖**(별도 주체) | 가공권역은 해당 없음(필드 센서 미보유) |

> ⚠️ 판별 서비스 ↔ RFC/DB Agent **연동 방식(직접 JDBC vs Agent 경유)** 은 설계 확정 필요.

## 2. 기능-모듈 매핑표

| 기능ID | 담당 모듈 | 헥사고날 레이어 / 구성요소 | 비고 |
|---|---|---|---|
| FAB-F01 강재 입고·적치 실적 수집 | ot-pipeline-fabrication | `adapter/out/legacy` → SSY(Oracle) 스케줄 작업 실적 조회 | ⚠️ 물리 테이블명 미확정 |
| FAB-F02 선별 실적 판별 | ot-pipeline-fabrication + ot-core | `application/service` → ot-core `application/port/in` 판별 유스케이스 | ⚠️ 자동 수집 방안 미확정 |
| FAB-F03 불출 실적 판별 | ot-pipeline-fabrication | `adapter/out/legacy`(YPWC140M·ZMMTA001) + `application/service` | 전처리 착수 트리거 |
| FAB-F04 전처리 통과 판정 | ot-pipeline-fabrication + ot-core | `adapter/out/legacy`(ProMES 마킹 상태) + `domain/statemachine` 전이 | `fabrication.yml` |
| FAB-F05 절단 실적 판별 | ot-pipeline-fabrication | `adapter/out/legacy`(YPWC310M) + `application/service` | 도면(DWG_NO) 단위 |
| FAB-F06 사상·모듬 실적 판별 | ot-pipeline-fabrication | `adapter/out/legacy`(YPWC820M·YPDG002M) + `application/service` | 모듬 단위 |
| FAB-F07 강재→도면→부재 전개 매핑 | ot-pipeline-fabrication | `domain`(키체인 조인 규칙 — zone 고유 순수 로직) | 프레임워크 비의존 |
| FAB-F08 부재→조립품·블록 롤업 집계 | ot-pipeline-fabrication | `application/service` + `application/port/out` 레거시 게이트웨이(YDEH060M/050M) | 조립품은 소급 반영 |
| FAB-F09 혼재 네스팅 실적 배분 | ot-pipeline-fabrication | `domain`(배분 산식 — 순수 로직) | ⚠️ 배분 규칙 미확정 |
| FAB-F10 겹장 백 처리 예외 보정 | ot-pipeline-fabrication | `application/service`(불출 실적 ↔ 마킹 상태 교차 검증) | FAB-F04 의존 |
| FAB-F11 공용재 수기 불출 보완 | ot-pipeline-fabrication | `adapter/out/legacy`(ProMES 수기 불출) | ⚠️ 소스 미확정 |
| FAB-F12 긴급 선별건 처리 | ot-pipeline-fabrication | `application/service`(긴급 상태값 분기) | 착수/완료 미세분화 |
| FAB-F13 입고·불출 지연 판별 | ot-pipeline-fabrication | `application/service` + 레거시 게이트웨이(설계 일정계획) | ⚠️ 기준 테이블 미확정 |
| FAB-F14 실적 저장·결과 통지 | ot-pipeline-fabrication | `adapter/out/persistence`(Hot DB) + `application/port/out` `ProcessResultNotifier` | ⚠️ 통지 구현 보류(프로토콜 미확정) |
| (공통) 판별 엔진 | ot-core | `domain/statemachine`, `application/port/in` 판별 유스케이스 | 4개 zone 공유 |
| (공통) 진입점 | ot-pipeline-fabrication | `adapter/in/provider`(OT Core가 호출하는 Provider 진입점) | ⚠️ 프로토콜 미확정 |
| (공통) 규칙 외부화 | — | `state-machine-configs/fabrication.yml` (`STATE_MACHINE_CONFIG_PATH` 주입) | 재빌드 없이 재시작 반영 |
| (레거시 취득) RFC Agent | **이 레포** | SAP RFC 연동으로 불출·절단·사상 실적, 일정계획 취득 | ISL Agent 아님 |
| (레거시 취득) DB Agent | **이 레포** | Oracle·레거시 DB 연동 취득(SSY·ProMES) | ISL Agent 아님 |

> **참고:** FAB-F01·F03·F04·F05·F06·F11·F13의 "레거시 게이트웨이" 조회는 위 RFC/DB Agent(이 레포)를 경유하거나 직접 접근한다 — 연동 방식은 ⚠️ 설계 확정 필요.

> ⚠️ **배치 주의:** `ot-pipeline-fabrication`은 OT-Server-B에 선행의장 모듈과 함께 기동된다. actuator 등 관리 포트를 모듈별로 분리한다(예: 8080/8081).
