## 1. 목적 · 페르소나 질문

- **P1 현장 관리자** — "지금 내 BAY에 뭐가 있고, 뭐가 막혔나." 공장을 눌러 BAY로 들어가면 그 BAY의 작업 목록(블록 단위)과 점검 필요 설비를 본다.
- **공통 진입** — 야드 전체 지도에서 공장·BAY 위치를 찾고, 해당 공정 화면(현황·3D·실적)을 **화면을 떠나지 않고** 창으로 열어 본다.
- 답하지 않는 질문(현 구현 없음): BAY 셀 뱃지 3종(체류·판별 보류·지연), 사외/미착수/범위 외 사유 표시, 수집 이상 배지. prd §6.1 대비 빈 부분이다.

## 4. 화면 정의표

**공통 규칙** (컨플루언스 화면설계서 1.2 중 이 화면에 해당하는 것)
- 메뉴는 상단 헤더의 가로 메뉴다(1280 이상에서 사이드바 없음). 선택된 메뉴는 주황 배경으로 강조한다.
- 야드 맵의 현황 · 3D · 실적 버튼은 화면을 떠나지 않고 창(미리보기)으로 띄운다. 창 안에서는 공장 목록과 [현황 | 실적] 탭을 감춘다.
- 창으로 여는 조립 · 선행의장 · 선행도장 화면은 현황 · 실적 버튼에 따라 [현황]이나 [실적]으로 열린다(창 안에는 갈래 탭이 없다).
- 모든 수치는 실연동 전 목업 데이터다(결정론 생성). 레거시 원천은 하루 1회, 센서(LiDAR · PLC) 원천은 실시간이 전제다.

### 4.6 데이터 · 비고

지금은 전부 목업이다. 괄호 안은 실제 연동 시의 원천과 갱신 주기. 자세한 규칙은 [부록 A](#부록-a-화면-정의표-상세개발-참고).

- **지도·이름패·카드 경로** — 지번 기준정보. 공장 코드↔명칭 `[미확정 6]`(코드 그대로 표기).
- **블록 검색**(4.1-1) — 레거시 호선·블록 마스터(하루 1회) + 현재 위치(실시간). 블록 목록 범위 `[미확정 1]` · 결과 형태 `[미확정 5]`. 지도에 없는 블록의 사유(사외/미착수/범위 외) 표시 없음 `[미확정 9]`.
- **작업 줄 · 진행 작업**(4.2-5, 4.3-5, 4.4-2·3) — 현재 위치·판별(실시간, 조립·의장) · 도장 스텝(레거시, 하루 1회). 카드 단위가 블록이라 기능 정의서의 블록×송선/GDO 단위와 다르다 `[확인 필요]`. 기준 시각·"실시간" 표시 없음 `[확인 필요]`.
- **점검 필요 핀·하이라이트** — 늘 켜져 있다(켜고 끄는 토글 없음). 핀은 노란 물방울(경고 아이콘), 강조는 건물 아래 바닥에. 설비 연결 상태(실시간 — 조립·의장 센서, 도장 PLC).
- **현황·3D·실적 버튼** — 공정별 노출이 다르다: 조립·의장 = 세 버튼, 도장 = 현황·실적(3D 없음), 가공 = 실적만(4.4-1). 갈 곳이 없으면 버튼을 그리지 않는다.
- **카메라 값**(4.1-2) — 운영 화면에 남길지 `[확인 필요]`(개발·검토용). 공정 색은 기본 시안으로 고정(시안 고르기 없음).
- **조작 안내** — 왼쪽 아래 한 줄 안내에 아직 "베이를 누르면 지번 상세"라고 적혀 있다. 드릴다운은 베이까지다 `[확인 필요 2]`.
- **헤더** — 사이드바 없음 `[확인 필요 1]` · 가운데 "수집 정상"은 고정 문구.
