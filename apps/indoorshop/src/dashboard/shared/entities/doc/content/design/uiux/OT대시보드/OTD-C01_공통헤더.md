## 1. 목적 · 페르소나 질문

| 페르소나 | 답하는 질문 |
|---|---|
| P1 현장 관리자 · P2 계획 스케줄러 · P3 운영자 | "어느 화면으로 가야 하나, 지금 위험·주의 알람이 몇 건인가?" |

## 2. 진입 · 화면 ID

| 화면 ID | 여는 곳 | 목적 |
|---|---|---|
| OTD-C01 | 모든 화면 위에 고정 | 메뉴 · 통합 검색 · 최근 본 화면 · 즐겨찾기 · 화면 안내 · 수집 상태와 시각 · 알람 · 계정 메뉴 |

- 메뉴는 상단 헤더의 가로 메뉴다(1280 이상에서 사이드바 없음). 선택된 메뉴는 주황 배경으로 강조한다.
- 야드 맵의 화면 창(미리보기, `?embed=1`) 안에서는 헤더가 없다.

## 5. 상태 변형

| 상태 | 현 구현 동작 |
|---|---|
| 알람 없음 | 알람 아이콘에 건수가 붙지 않는다. |
| 수집 이상 | 표시 없음 — "수집 정상"이 고정 표기라 실제 수집 상태를 따르지 않는다 `[확인 필요]` |
| 창(임베드) | 헤더 전체를 감춘다. |

## 6. 미확정

- `[확인 필요]` 수집 상태 표기("수집 정상")를 실제 수집 상태와 잇는 시점·기준.
- `[확인 필요]` 메뉴 위치 — prd §6.10·design-system §4는 좌측 사이드바를 전제하나 현 구현은 헤더 가로 메뉴다(현 구현 유지 확정, prd 개정 필요).
- `[확인 필요]` 선택 메뉴·로고의 주황(accent)은 design-system.md에 없는 색이다.
